### قرار AGPL (يحتاج قرارك، لا يوقف العمل)
Ghostscript وPyMuPDF مرخصان AGPL: عند تقديمهما كخدمة عبر الشبكة يجب إتاحة كود الخادم (بما فيه تعديلاتك) لمن يستخدمه، **أو** شراء ترخيص تجاري من Artifex. الخياران:
1. **نشر كود `backend/` علناً** (مثلاً مستودع عام منفصل) — مجاني ومتوافق.
2. **ترخيص تجاري من Artifex** لـ PyMuPDF وGhostscript — السعر بالتفاوض مع Artifex.

تطبيق iOS لا يحتوي أي كود AGPL.

### جودة التحويل — بصراحة
- لا يوجد تحويل PDF→Word/Excel/PowerPoint مطابق 100٪ بأي محرك. ما اختُبر هنا: نص عربي وإنجليزي، جدول، صورة، 100 صفحة، ملف محمي.
- إذا احتجت دقة أعلى للمستندات المعقدة: محركات تجارية متخصصة (مثل Adobe PDF Services API، أو Aspose.PDF، أو ABBYY FineReader Engine). لم يُربط أي منها؛ تحتاج حساباً ومفتاحاً منك. الخادم مصمم بحيث تُستبدل دالة التحويل في `app/tools/from_pdf.py` دون تغيير التطبيق.
- لم يُستخدم iLovePDF API أو أي خدمة مدفوعة.

## التكلفة التقديرية للتشغيل
| البند | التكلفة |
|---|---|
| حساب Apple Developer | 99 دولاراً سنوياً |
| خادم المعالجة (4 أنوية / 8 ج.ب ذاكرة يكفي للبداية) | ~10–40 دولاراً شهرياً حسب المزود |

| GitHub Actions (macOS) | مجاني للمستودعات العامة؛ للخاصة دقائق macOS محسوبة من الرصيد |
